# Monthly Financial Reporting & FP&A Analysis

## Overview

This project demonstrates a practical financial reporting and FP&A workflow for a small/medium-sized business using Microsoft Excel.

The analysis focuses on understanding financial performance, comparing actual results against budget, identifying key variances, and forecasting short-term cash requirements.

## Objectives

- Prepare monthly financial reports from transaction-level data
- Analyse revenue, expenses, and profitability
- Compare budgeted performance with actual results
- Identify and interpret favourable and unfavourable variances
- Analyse key revenue and expense drivers
- Prepare a 13-week cash flow forecast to assess short-term liquidity
- Present financial KPIs and trends in a management-friendly format

## Key Analysis

### 1. Monthly Financial Reporting
Prepared a structured monthly financial view covering:

- Revenue
- Operating expenses
- Profitability
- Major expense categories
- Monthly performance trends

### 2. Budget vs Actual Analysis

Compared budgeted and actual financial performance to identify:

- Revenue variances
- Expense variances
- Favourable and unfavourable variances
- Significant deviations from budget
- Key drivers of financial performance

### 3. 13-Week Cash Flow Forecast

Developed a short-term cash flow forecast to evaluate:

- Expected cash inflows
- Expected cash outflows
- Weekly net cash movement
- Opening and closing cash balances
- Projected liquidity requirements

### 4. Financial KPI Analysis

Tracked key indicators to support management decision-making, including:

- Revenue
- Operating expenses
- Profitability
- Budget variance
- Cash position
- Cash flow trends

## Project Outcome

The project converts raw financial data into structured management information that can be used to evaluate business performance, understand budget deviations, and assess near-term cash requirements.

The analysis demonstrates the core workflow used in entry-level financial analyst and FP&A roles:  
**Data → Financial Reporting → Variance Analysis → Forecasting → Management Insights**
